Summary: 2026年9月16日〜9月25日の Azure Update まとめ。GA 11件、パブリックプレビュー 9件、リタイア 5件の計25件。

2026年9月16日〜9月25日に発表された Azure Update のまとめです。

## GA（一般提供）- 11件

- Instant Access for VM restore points[^1]
- Azure Container Apps Sandboxes[^2]
- Azure Container Apps Express[^3]
- Azure Sphere OS version 26.09[^4]
- Azure Functions の PowerShell 7.6 サポート[^5]
- Microsoft Foundry エージェントの有効化・無効化コントロール（Agent 365）[^6]
- Microsoft Foundry エージェントの Microsoft 365 Copilot および Teams への公開[^7]
- Azure Database for PostgreSQL Flexible Server の論理レプリケーションスロット同期ステータスメトリック[^8]
- Azure Database for PostgreSQL の新しいトラブルシューティングガイド[^9]
- Azure Database for PostgreSQL エラスティッククラスターの PG18 サポート[^10]
- Azure Virtual Network Manager のハイスケールメッシュ[^11]

## パブリックプレビュー - 9件

- AKS の Flex Nodes[^12]
- VS Code での Azure アプリ構築のためのガイド付き Copilot エクスペリエンス[^13]
- Foundry Agent Service の Foundry Routines[^14]
- SAP 向け Mdsv4 および Msv4 シリーズ仮想マシン[^15]
- Microsoft Foundry ホステッドエージェントのネットワークエグレスコントロール[^16]
- Azure Payments HSM v2[^17]
- Azure SQL の2026年9月中旬アップデート[^18]
- ホステッドコントロールプレーンを使用した Azure Red Hat OpenShift[^19]
- Azure Database for PostgreSQL の PostgreSQL スキルおよび MCP プラグイン[^20]

## リタイア（廃止予定）- 5件

- Azure Communication Services (ACS) スタンドアロンサービスは2028年9月30日に廃止予定[^21]
- PowerShell 7.4 のサポートは2026年11月10日に終了[^22]
- .NET 8 および .NET 9 のサポートは2026年11月10日に終了[^23]
- Node.js 22 のサポートは2027年4月30日に終了[^24]
- SAP コンテナーイメージは2026年10月14日に削除予定[^25]

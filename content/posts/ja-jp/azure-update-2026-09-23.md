2026年9月14日〜9月23日に発表された Azure Update のまとめです。

## GA

1. **Azure Sphere OS version 26.09 が利用可能に**[^1]
2. **Azure Functions が PowerShell 7.6 をサポート**[^2]
3. **Microsoft Foundry エージェントの有効化・無効化コントロール（Agent 365）**[^3]
4. **Microsoft Foundry エージェントを Microsoft 365 Copilot および Teams に公開**[^4]
5. **Azure Database for PostgreSQL Flexible Server の論理レプリケーションスロット同期ステータスメトリック**[^5]
6. **Azure Database for PostgreSQL の新しいトラブルシューティングガイド**[^6]
7. **Azure Database for PostgreSQL エラスティッククラスターで PG18 をサポート**[^7]
8. **Azure Virtual Network Manager のハイスケールメッシュ**[^8]

## パブリックプレビュー

1. **AKS 向け Flex Nodes**[^9]
2. **VS Code で Azure アプリを構築するためのガイド付き Copilot エクスペリエンス**[^10]
3. **Foundry Agent Service の Foundry Routines**[^11]
4. **SAP 向け Mdsv4 および Msv4 シリーズ仮想マシン**[^12]
5. **Microsoft Foundry ホステッドエージェントのネットワークエグレスコントロール**[^13]
6. **Azure Payments HSM v2**[^14]
7. **Azure SQL の 2026年9月中旬アップデート**[^15]
8. **Azure Red Hat OpenShift のホステッドコントロールプレーン**[^16]
9. **Azure Database for PostgreSQL 向け PostgreSQL スキルおよび MCP プラグイン**[^17]
10. **Azure Application Gateway での HTTP/3 over QUIC サポート**[^18]

## リタイア

1. **Node.js 22 のサポートが 2027年4月30日に終了**[^19]
2. **SAP コンテナーイメージが 2026年10月14日に削除**[^20]

## その他

1. **Azure Virtual Desktop 向け新しい Windows App クライアント側エンドポイント**[^21]

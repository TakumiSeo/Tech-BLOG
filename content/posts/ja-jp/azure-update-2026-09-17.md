Summary: 2026年9月8日〜9月17日の Azure Update まとめ。GA 6件、パブリックプレビュー 5件、リタイア 2件、その他 1件の計14件。

## GA

- Azure Functions Flex Consumption で TLS/SSL 証明書とエンドツーエンド TLS 暗号化がサポートされました[^1]
- Azure Copilot Troubleshooting Agent が一般提供されました[^2]
- Azure Storage のユーザーバウンド ユーザー委任 SAS が一般提供されました[^3]
- Azure Ephemeral OS Disk で VM/VMSS 向けのフルキャッシュがサポートされました[^4]
- Playwright Workspaces が Australia East、Japan East、Switzerland North リージョンで利用可能になりました[^5]
- Azure Developer CLI (azd) Extension Framework が一般提供されました[^6]

## パブリックプレビュー

- Azure SQL の 2026 年 9 月中旬アップデート（論理サーバーのソフトデリート構成など）がパブリックプレビューになりました[^7]
- Azure Red Hat OpenShift のホステッドコントロールプレーンがパブリックプレビューになりました[^8]
- Azure Database for PostgreSQL 向け PostgreSQL スキルおよび MCP プラグインがパブリックプレビューになりました[^9]
- Azure Application Gateway で HTTP/3 over QUIC のサポートがパブリックプレビューになりました[^10]
- オンプレミス SMB ファイル共有から Azure Files (SMB) へのエージェントレス移行がパブリックプレビューになりました[^11]

## リタイア

- SAP コンテナーイメージが 2026 年 10 月 14 日に削除されます。SAP エージェントレスコネクタへの移行が必要です[^12]
- Azure Kubernetes Service の Azure Linux with OS Guard が 2026 年 12 月 10 日に廃止されます[^13]

## その他

- Azure Virtual Desktop の新しい Windows App クライアント側エンドポイントが 2026 年 10 月に導入されます[^14]

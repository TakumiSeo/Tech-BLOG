Summary: 2026年9月20日〜9月29日の Azure Update まとめ。GA 9件、パブリックプレビュー 4件、リタイア 4件の計17件。

2026年9月20日〜9月29日に発表された Azure Update のまとめです。

## GA

1. **Azure SQL のベクトル検索およびベクトルインデックス**が一般提供開始[^1]。
2. **Azure SQL Managed Instance の2026年9月後半アップデート**が一般提供開始[^2]。
3. **ルクセンブルク — Azure Extended Zones** が一般提供開始[^3]。
4. **Azure Backup for Elastic SAN** が一般提供開始[^4]。
5. **VM 復元ポイントの Instant Access** が一般提供開始[^5]。
6. **Azure Container Apps Sandboxes** が一般提供開始[^6]。
7. **Azure Container Apps Express** が一般提供開始[^7]。
8. **Azure Sphere OS バージョン 26.09** が一般提供開始[^8]。
9. **Azure Functions の PowerShell 7.6 サポート**が一般提供開始[^9]。

## パブリックプレビュー

1. **Azure SQL Dev Hub** がパブリックプレビュー開始[^10]。
2. **Azure HorizonDB が PostgreSQL 18 をサポート**、パブリックプレビュー開始[^11]。
3. **AKS 向け Flex Nodes** がパブリックプレビュー開始[^12]。
4. **VS Code での Azure アプリ構築向けガイド付き Copilot エクスペリエンス**がパブリックプレビュー開始[^13]。

## リタイア

1. **Azure Communication Services (ACS) スタンドアロンサービス**が 2028年9月30日に廃止予定[^14]。
2. **PowerShell 7.4 のサポート**が 2026年11月10日に終了[^15]。
3. **.NET 8 および .NET 9 のサポート**が 2026年11月10日に終了。.NET 10 へのアップグレードが必要[^16]。
4. **Node.js 22 のサポート**が 2027年4月30日に終了[^17]。

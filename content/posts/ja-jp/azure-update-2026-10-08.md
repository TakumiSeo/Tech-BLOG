2026年9月29日〜10月8日における Azure Update のまとめです。GA 16件、パブリックプレビュー 19件、リタイア 13件、その他 2件の計50件のアップデートがありました。

## 一般提供 (GA)

- Generally Available: Anyscale on Azure (Azure Kubernetes Service (AKS))[^1]
- Generally Available: Enabling the Bulk admin role for SQL Server on Linux[^2]
- Generally Available: SQL Server on Azure Virtual Machines in Azure Bleu  (SQL Server on Azure Virtual Machines)[^3]
- Generally Available: Storage optimized Lasv5 and Laosv5 Azure VM series  (Virtual Machines)[^4]
- Generally Available: Azure Arc-enabled SQL Server in Germany West Central[^5]
- Generally Available: Azure Arc-enabled SQL Server Available in Italy North[^6]
- Generally Available: Azure SQL updates for late-September 2026 (Azure SQL Database)[^7]
- Generally Available: Azure Database for PostgreSQL Flexible Server supports cross-tenant customer-managed keys (CMK)  (Azure Database for PostgreSQL)[^8]
- Generally Available: SQL Server on Azure Local Disconnected (ALDO) [^9]
- Generally Available: SQL Server support on Azure Local connected mode [^10]
- Generally Available: Database DevOps in SSMS powered by SQL projects  (Azure SQL Database)[^11]
- Generally Available: SQL Formatter  (Azure SQL Database)[^12]
- Generally Available: SQL Migration Agent Skills for assessment, migration, and validation [^13]
- Generally Available: Support for large volume breakthrough mode (Azure NetApp Files)[^14]
- Generally Available: Storage with cool access enhancement  (Azure NetApp Files)[^15]
- Generally Available: Vector search and vector indexes in Azure SQL  (Azure SQL Database)[^16]

- Public Preview: Azure HorizonDB expands to additional regions (Azure HorizonDB)[^18]
- Public Preview: Azure Backup for PostgreSQL flexible server and elastic cluster (v2) (Azure Backup, Azure Database for PostgreSQL)[^19]
- Public Preview: IPv6 Support for Application Gateway WAF  (Application Gateway, Web Application Firewall)[^20]
- Public Preview:  Major version upgrades (MVU) for Azure Database for PostgreSQL elastic clusters  (Azure Database for PostgreSQL)[^21]
- Public Preview: Reader Endpoint for Azure Database for MySQL  (Azure Database for MySQL)[^22]
- Public Preview: SQL performance monitoring for SQL Server on Azure Virtual Machines  (SQL Server on Azure Virtual Machines)[^23]
- Public Preview: Ubuntu 26.04 support in AKS (Azure Kubernetes Service (AKS))[^24]
- Public Preview: Automatic Zone Placement for Virtual Machine Scale Sets (Virtual Machines)[^25]
- Public Preview: Azure Database for PostgreSQL Ultra Disk  (Azure Database for PostgreSQL)[^26]
- Public Preview: SQL Performance Monitoring for Azure SQL Database (Azure SQL Database)[^27]
- Public Preview: Performance monitoring for Azure Arc–enabled SQL Server  (Azure Arc)[^28]
- Public preview: Script-based deployment for SQL Server on Linux Azure VM  (SQL Server on Azure Virtual Machines)[^29]
- Public Preview: Azure SQL updates for late-September 2026  (Azure SQL Database, Azure SQL Managed Instance)[^30]
- Public Preview: Azure SQL Database Hyperscale Serverless auto-pause and auto-resume  (Azure SQL Database)[^31]
- Public Preview: Migrate directly from Azure Arc to Azure SQL Database, including Hyperscale (Azure SQL Database)[^32]
- Public Preview: Microsoft SQL Agent Skills (Azure SQL Database)[^33]
- Public Preview: Long-term retention (LTR) v2 for Azure Database for PostgreSQL (Azure Database for PostgreSQL)[^34]
- Public Preview : Microsoft entra kerberos authentication for Azure NetApp Files    (Azure NetApp Files)[^35]

## リタイア (Retirement)

- Retirement: Pod name dimension in AKS pod platform metrics (Azure Kubernetes Service (AKS))[^36]
- Retirement: Azure App Service on Azure Stack Hub (App Service, Azure Stack Hub)[^37]
- Retirement: Support for Java 8, 11 and 17 will end on September 1, 2027 (App Service)[^38]
- Retirement: Always Encrypted with Intel SGX Enclaves (Azure SQL Database)[^39]
- Retirement: DCsv3 and DCdsv3-series Azure Virtual Machines will be retired on October 31, 2029 (Linux Virtual Machines, Virtual Machines, Windows Virtual Machines)[^40]
- Retirement: NVv3-series Azure Virtual Machines (Virtual Machines)[^41]
- Retirement: NVv4-series Azure Virtual Machines (Virtual Machines)[^42]
- Retirement: Dv3, Dsv3, Ev3, and Esv3 Azure VMs  (Virtual Machines)[^43]
- Retirement: Transition to using standard tests for single-step availability testing in Azure Monitor application insights by September 30, 2028 (Application Insights, Azure Monitor)[^44]
- Retirement: Functions on Azure Container Apps V1  (Azure Container Apps)[^45]
- Retirement: Azure Arc enabled System Center Virtual Machine Manager will be retired September 30, 2029[^46]
- Retirement: Microsoft HPC Pack[^47]
- Retirement: Azure IoT Central will be retired on September 20, 2029 (Azure IoT Central)[^48]

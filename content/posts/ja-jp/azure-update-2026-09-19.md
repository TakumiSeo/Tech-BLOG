Summary: 2026年9月10日〜9月19日の Azure Update まとめ。GA 8件、パブリックプレビュー 9件、リタイア 2件、その他 1件の計20件。

2026年9月10日〜9月19日に更新された Azure Update のまとめです。

## 一般提供 (Generally Available)

- Microsoft Foundry エージェントの Agent 365 における有効化・無効化コントロールが一般提供開始[^1]
- Microsoft Foundry エージェントの Microsoft 365 Copilot および Teams への公開機能が一般提供開始[^2]
- Azure Database for PostgreSQL フレキシブルサーバーにおける論理レプリケーションスロットの同期状態メトリクスが一般提供開始[^3]
- Azure Database for PostgreSQL の新しいトラブルシューティングガイドが一般提供開始[^4]
- Azure Database for PostgreSQL エラスティッククラスターにおける PG18 サポートが一般提供開始[^5]
- Azure Virtual Network Manager のハイスケールメッシュが一般提供開始[^6]
- Azure Functions Flex Consumption における TLS/SSL 証明書およびエンドツーエンド TLS 暗号化サポートが一般提供開始[^7]
- Azure Copilot Troubleshooting Agent が一般提供開始[^8]

## パブリックプレビュー (Public Preview)

- Microsoft Foundry Agent Service における Foundry Routines がパブリックプレビュー開始[^9]
- SAP 向け Mdsv4 および Msv4 シリーズ仮想マシンがパブリックプレビュー開始[^10]
- Microsoft Foundry のホステッドエージェント向けネットワーク送信制御がパブリックプレビュー開始[^11]
- Azure Payments HSM v2 がパブリックプレビュー開始[^12]
- 2026年9月中旬の Azure SQL アップデートがパブリックプレビュー開始[^13]
- Azure Red Hat OpenShift のホステッドコントロールプレーンがパブリックプレビュー開始[^14]
- Azure Database for PostgreSQL 向け PostgreSQL スキルおよび MCP プラグインがパブリックプレビュー開始[^15]
- Azure Application Gateway における HTTP/3 over QUIC サポートがパブリックプレビュー開始[^16]
- オンプレミス SMB ファイル共有の Azure Files (SMB) へのエージェントレス移行がパブリックプレビュー開始[^17]

## リタイア (Retirement)

- SAP コンテナーイメージが 2026年10月14日に削除予定[^18]
- Azure Kubernetes Service における Azure Linux with OS Guard がリタイア[^19]

## その他

- Azure Virtual Desktop の新しい Windows App クライアント側エンドポイントが発表[^20]

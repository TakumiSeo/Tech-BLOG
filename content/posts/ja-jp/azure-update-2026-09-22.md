Summary: 2026年9月13日〜9月22日の Azure Update まとめ。GA 8件、パブリックプレビュー 9件、リタイア 1件、その他 1件の計19件。

2026年9月13日〜9月22日に発表された Azure Update のまとめです。

## 一般提供 (GA)

- **Azure Sphere OS バージョン 26.09 の一般提供**[^1]
- **Azure Functions の PowerShell 7.6 サポートが一般提供**[^2]
- **Agent 365 における Microsoft Foundry エージェントの有効化・無効化コントロールが一般提供**[^3]
- **Microsoft Foundry エージェントの Microsoft 365 Copilot および Teams への発行が一般提供**[^4]
- **Azure Database for PostgreSQL フレキシブルサーバーの論理レプリケーションスロット同期ステータスメトリクスが一般提供**[^5]
- **Azure Database for PostgreSQL の新しいトラブルシューティングガイドが一般提供**[^6]
- **Azure Database for PostgreSQL エラスティッククラスターの PG18 サポートが一般提供**[^7]
- **Azure Virtual Network Manager のハイスケールメッシュが一般提供**[^8]

## パブリックプレビュー

- **VS Code で Azure アプリを構築するためのガイド付き Copilot エクスペリエンスがパブリックプレビュー**[^9]
- **Foundry Agent Service の Foundry Routines がパブリックプレビュー**[^10]
- **SAP 向け Mdsv4 および Msv4 シリーズ仮想マシンがパブリックプレビュー**[^11]
- **Microsoft Foundry ホステッドエージェントのネットワークエグレスコントロールがパブリックプレビュー**[^12]
- **Azure Payments HSM v2 がパブリックプレビュー**[^13]
- **Azure SQL の 2026年9月中旬アップデートがパブリックプレビュー**[^14]
- **Azure Red Hat OpenShift のホステッドコントロールプレーンがパブリックプレビュー**[^15]
- **Azure Database for PostgreSQL の PostgreSQL スキルおよび MCP プラグインがパブリックプレビュー**[^16]
- **Azure Application Gateway の HTTP/3 over QUIC サポートがパブリックプレビュー**[^17]

## リタイア

- **SAP コンテナーイメージが 2026年10月14日に削除予定**[^18]

## その他

- **Azure Virtual Desktop の新しい Windows App クライアント側エンドポイントを発表**[^19]

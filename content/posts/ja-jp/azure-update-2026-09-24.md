Summary: 2026年9月15日〜9月24日の Azure Update まとめ。GA 10件、パブリックプレビュー 9件、リタイア 4件の計23件。

2026年9月15日〜9月24日における Azure Update のまとめです。

## GA (10件)

- Azure Container Apps Sandboxes が一般提供開始[^1]
- Azure Container Apps Express が一般提供開始[^2]
- Azure Sphere OS バージョン 26.09 が利用可能[^3]
- Azure Functions で PowerShell 7.6 のサポートが一般提供開始[^4]
- Agent 365 における Microsoft Foundry エージェントの有効化・無効化コントロール[^5]
- Microsoft Foundry エージェントの Microsoft 365 Copilot および Teams への発行[^6]
- Azure Database for PostgreSQL フレキシブルサーバーの論理レプリケーションスロット同期ステータスメトリック[^7]
- Azure Database for PostgreSQL の新しいトラブルシューティングガイド[^8]
- Azure Database for PostgreSQL エラスティッククラスターで PG18 をサポート[^9]
- Azure Virtual Network Manager のハイスケールメッシュ[^10]

## パブリックプレビュー (9件)

- AKS 向け Flex Nodes[^11]
- VS Code で Azure アプリを構築するためのガイド付き Copilot エクスペリエンス[^12]
- Foundry Agent Service における Foundry Routines[^13]
- SAP 向け Mdsv4 および Msv4 シリーズ仮想マシン[^14]
- Microsoft Foundry のホステッドエージェント向けネットワークエグレスコントロール[^15]
- Azure Payments HSM v2[^16]
- 2026年9月中旬の Azure SQL アップデート[^17]
- ホステッドコントロールプレーンを備えた Azure Red Hat OpenShift[^18]
- Azure Database for PostgreSQL 向け PostgreSQL スキルおよび MCP プラグイン[^19]

## リタイア (4件)

- PowerShell 7.4 のサポートが2026年11月10日に終了[^20]
- .NET 8 および .NET 9 のサポートが2026年11月10日に終了—アプリを .NET 10 にアップグレード[^21]
- Node.js 22 のサポートが2027年4月30日に終了[^22]
- SAP コンテナーイメージが2026年10月14日に削除[^23]

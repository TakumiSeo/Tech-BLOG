Summary: 2026年9月3日〜9月12日の Azure Update まとめ。Azure Storage Mover のエージェントレス SMB 移行のパブリックプレビューや Azure Linux with OS Guard の廃止告知など計10件。

2026年9月3日〜9月12日に更新された Azure Update のまとめです。

## GA

- **Azure Functions Flex Consumption で TLS/SSL 証明書およびエンドツーエンド TLS 暗号化をサポート**[^1]
- **Azure Copilot Troubleshooting Agent**[^2]
- **Azure Storage のユーザーバウンド ユーザー委任 SAS**[^3]
- **VM/VMSS 向け Azure Ephemeral OS Disk のフルキャッシュ対応**[^4]
- **Playwright Workspaces が Australia East、Japan East、Switzerland North で利用可能に**[^5]
- **Azure Developer CLI (azd) Extension Framework**[^6]
- **Azure Virtual Network Manager IPAM の追加リージョン展開**[^7]
- **Azure Site Recovery が NVMe ディスクコントローラー搭載の Linux Azure VM をサポート**[^8]

## Public Preview

- **Azure Storage Mover によるオンプレミス SMB ファイル共有から Azure Files (SMB) へのエージェントレス移行**[^9]

## Retirement

- **Azure Kubernetes Service における Azure Linux with OS Guard の廃止（2026年12月10日）**[^10]

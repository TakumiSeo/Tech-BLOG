Summary: 2026年9月1日〜9月10日の Azure Update まとめ。ユーザー委任 SAS のユーザーバインドや Azure Ephemeral OS Disk の完全キャッシュ対応の GA など計17件。

## GA

- User-bound user delegation SAS for Azure Storage の一般提供開始[^1]
- Azure Ephemeral OS Disk with full caching for VM/VMSS の一般提供開始[^2]
- Playwright Workspaces が Australia East、Japan East、Switzerland North で利用可能に[^3]
- Azure Developer CLI (azd) Extension Framework の一般提供開始[^4]
- Azure Virtual Network Manager IPAM の追加リージョン展開が一般提供開始[^5]
- Azure Site Recovery が NVMe ディスクコントローラー搭載 Linux Azure VM をサポート[^6]
- Microsoft Defender for Cloud が Azure Container Apps をサポート（サーバーレスコンテナーポスチャ）[^7]
- Windows Server 2025 on AKS の一般提供開始[^8]
- Artifact Streaming on AKS の一般提供開始[^9]
- Confidential VMs for Azure Linux の一般提供開始[^10]
- Microsoft Marketplace で購入注文マッピングが利用可能に[^11]
- Azure Firewall auto-learn SNAT routes の一般提供開始[^12]
- Azure Copilot Observability Agent が Basic および Auxiliary テーブルプランをサポート[^13]
- Azure Monitor Auxiliary Logs Plan が Azure Government および China リージョンで利用可能に[^14]
- Azure Monitor Auxiliary Logs Plan が Azure テーブルおよびプラン切り替えをサポート[^15]

## Public Preview

- Azure Front Door のプロファイルおよびルートレベル WAF ポリシーのパブリックプレビュー[^16]

## Private Preview

- Azure Database for MySQL の Reader Endpoint のプライベートプレビュー[^17]

Summary: 2026年9月18日〜9月27日の Azure Update まとめ。GA 10件、パブリックプレビュー 6件、リタイア 4件の計20件。

## 一般提供開始（GA） - 10件

- **Generally Available: Instant Access for VM restore points**[^1]
- **Generally Available: Azure Container Apps Sandboxes**[^2]
- **Generally Available: Azure Container Apps Express**[^3]
- **Generally Available: Azure Sphere OS version 26.09 is now available**[^4]
- **Generally Available: Azure Functions support for PowerShell 7.6**[^5]
- **Generally Available: Enable and disable controls for Microsoft Foundry agents in Agent 365**[^6]
- **Generally Available: Publishing Microsoft Foundry agents to Microsoft 365 Copilot and Teams**[^7]
- **Generally Available: Logical replication slot sync status metric for Azure PostgreSQL Flexible Server **[^8]
- **Generally Available: New and improved troubleshooting guides for Azure Database for PostgreSQL **[^9]
- **Generally Available: PG18 support for Azure Database for PostgreSQL elastic clusters **[^10]

## パブリックプレビュー - 6件

- **Public Preview: Azure HorizonDB supports PostgreSQL 18**[^11]
- **Public Preview: Flex Nodes for AKS**[^12]
- **Public Preview: Introducing a Guided Copilot Experience for Building Azure Apps in VS Code**[^13]
- **Public Preview: Foundry Routines in Foundry Agent Service**[^14]
- **Public Preview: Mdsv4 and Msv4 Series Virtual Machines for SAP**[^15]
- **Public Preview: Network egress controls for hosted agents in Microsoft Foundry**[^16]

## リタイア - 4件

- **Retirement: Azure Communication Services (ACS) standalone services will be retired on September 30, 2028**[^17]
- **Retirement: Support for PowerShell 7.4 ends on November 10, 2026**[^18]
- **Retirement: Support for .NET 8 and .NET 9 ends on November 10, 2026—upgrade your apps to .NET 10  **[^19]
- **Retirement: Support for Node.js 22 ends on April 30, 2027**[^20]

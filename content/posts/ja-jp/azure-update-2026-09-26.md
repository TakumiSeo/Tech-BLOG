Summary: 2026年9月17日〜9月26日の Azure Update まとめ。GA 11件、パブリックプレビュー 7件、リタイア 4件の計22件。

2026年9月17日〜9月26日に更新された Azure Update のまとめです。

## 一般提供 (GA) - 11件

- **Instant Access for VM restore points** — 仮想マシン（VM）のリストアポイントに対する即時アクセスが一般提供開始[^1]。
- **Azure Container Apps Sandboxes** — Azure Container Apps のサンドボックス機能が一般提供開始[^2]。
- **Azure Container Apps Express** — Azure Container Apps Express が一般提供開始[^3]。
- **Azure Sphere OS version 26.09** — Azure Sphere OS バージョン 26.09 が一般提供開始[^4]。
- **Azure Functions support for PowerShell 7.6** — Azure Functions の PowerShell 7.6 サポートが一般提供開始[^5]。
- **Enable and disable controls for Microsoft Foundry agents in Agent 365** — Microsoft Foundry エージェントの Agent 365 における有効化・無効化コントロールが一般提供開始[^6]。
- **Publishing Microsoft Foundry agents to Microsoft 365 Copilot and Teams** — Microsoft Foundry エージェントの Microsoft 365 Copilot および Teams への発行が一般提供開始[^7]。
- **Logical replication slot sync status metric for Azure PostgreSQL Flexible Server** — Azure Database for PostgreSQL フレキシブルサーバーの論理レプリケーションスロット同期ステータスメトリクスが一般提供開始[^8]。
- **New and improved troubleshooting guides for Azure Database for PostgreSQL** — Azure Database for PostgreSQL の新しいトラブルシューティングガイドが一般提供開始[^9]。
- **PG18 support for Azure Database for PostgreSQL elastic clusters** — Azure Database for PostgreSQL エラスティッククラスターの PG18 サポートが一般提供開始[^10]。
- **High-scale mesh in Azure Virtual Network Manager** — Azure Virtual Network Manager のハイスケールメッシュが一般提供開始[^11]。

## パブリックプレビュー - 7件

- **Azure HorizonDB supports PostgreSQL 18** — Azure HorizonDB が PostgreSQL 18 をサポート（パブリックプレビュー）[^12]。
- **Flex Nodes for AKS** — Azure Kubernetes Service (AKS) の Flex Nodes がパブリックプレビュー開始[^13]。
- **Introducing a Guided Copilot Experience for Building Azure Apps in VS Code** — VS Code での Azure アプリ構築をガイドする Copilot エクスペリエンスがパブリックプレビュー開始[^14]。
- **Foundry Routines in Foundry Agent Service** — Foundry Agent Service の Foundry Routines がパブリックプレビュー開始[^15]。
- **Mdsv4 and Msv4 Series Virtual Machines for SAP** — SAP 向け Mdsv4 および Msv4 シリーズ仮想マシンがパブリックプレビュー開始[^16]。
- **Network egress controls for hosted agents in Microsoft Foundry** — Microsoft Foundry のホステッドエージェント向けネットワークエグレスコントロールがパブリックプレビュー開始[^17]。
- **Azure Payments HSM v2** — Azure Payments HSM v2 がパブリックプレビュー開始[^18]。

## リタイア - 4件

- **Azure Communication Services (ACS) standalone services will be retired on September 30, 2028** — Azure Communication Services (ACS) スタンドアロンサービスが 2028年9月30日に廃止予定[^19]。
- **Support for PowerShell 7.4 ends on November 10, 2026** — PowerShell 7.4 のサポートが 2026年11月10日に終了[^20]。
- **Support for .NET 8 and .NET 9 ends on November 10, 2026** — .NET 8 および .NET 9 のサポートが 2026年11月10日に終了。.NET 10 へのアップグレードが推奨[^21]。
- **Support for Node.js 22 ends on April 30, 2027** — Node.js 22 のサポートが 2027年4月30日に終了[^22]。

Summary: 2026年9月19日〜9月28日の Azure Update まとめ。GA 5件、パブリックプレビュー 3件、リタイア 4件の計12件。

2026年9月19日〜9月28日に更新された Azure Update のまとめです。

## GA

- VM リストアポイントの Instant Access が一般提供開始[^1]
- Azure Container Apps Sandboxes が一般提供開始[^2]
- Azure Container Apps Express が一般提供開始[^3]
- Azure Sphere OS バージョン 26.09 が一般提供開始[^4]
- Azure Functions の PowerShell 7.6 サポートが一般提供開始[^5]

## パブリックプレビュー

- Azure HorizonDB が PostgreSQL 18 をサポート[^6]
- AKS 向け Flex Nodes がパブリックプレビュー[^7]
- VS Code で Azure アプリ構築を支援するガイド付き Copilot エクスペリエンスがパブリックプレビュー[^8]

## リタイア

- Azure Communication Services (ACS) スタンドアロンサービスが廃止予定[^9]
- PowerShell 7.4 のサポートが 2026年11月10日に終了[^10]
- .NET 8 および .NET 9 のサポートが 2026年11月10日に終了[^11]
- Node.js 22 のサポートが 2027年4月30日に終了[^12]
